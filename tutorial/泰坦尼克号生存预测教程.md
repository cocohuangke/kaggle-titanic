# 第0章 方法论框架 —— 从理论到实战的思维转换

## 0.1 为什么需要方法论？

你可能在课堂上学过：数据清洗 → 特征工程 → 模型训练 → 评估。这个流程没错，但太粗了。在实际竞赛（和实际工作）中，你面临的问题是：

- **从哪里开始？** 拿到数据第一步干什么？
- **何时停止？** 一直调参有没有尽头？
- **怎么判断方向对不对？** 改了一个特征，分数是升了还是降了？
- **怎样可复现？** 三天后回来看，你还记得自己做了什么吗？

方法论就是回答这些问题的框架。

## 0.2 通用竞赛流水线（6步法）

## 0.3 五条黄金法则

在开始之前，请记住这五条来自Kaggle Grandmaster（顶级选手）的经验：

| 法则 | 解释 | 常见错误 |
|------|------|----------|
| **1. 交叉验证优于排行榜** | 你的CV分数才是真实水平，不要追着排行榜跑 | 反复提交试探LB分数，浪费时间且过拟合 |
| **2. 预处理必须在折内完成** | 填充、编码、缩放都只能用训练折的数据，不能偷看验证折 | 在全部数据上fit_encoder再split，导致数据泄漏 |
| **3. 特征工程 > 模型选择** | 一个好特征顶十个模型切换 | 纠结用XGBoost还是LightGBM，却忽略了特征 |
| **4. 多样化模型胜过单模型** | 至少跑3个不同类型的模型再融合 | 只用一个模型反复调参 |
| **5. 一次只改一个变量** | 每次实验只改一个东西，记录结果 | 同时改3个参数，不知道哪个起效 |

# 第2章 探索性数据分析（EDA）

> **核心思想**：EDA不是为了画好看的图，而是为了**发现规律、提出假设**。每张图都应该帮你做一个决策。

## 2.1 目标变量分布

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# 计数
train['Survived'].value_counts().plot(kind='bar', ax=axes[0], color=['#E24B4A', '#1D9E75'])
axes[0].set_title('生存情况（计数）')
axes[0].set_xlabel('0=遇难, 1=生存')
for c in axes[0].containers:
    axes[0].bar_label(c)

# 比例
train['Survived'].value_counts(normalize=True).plot(kind='pie', ax=axes[1],

axes[1].set_ylabel('')

plt.tight_layout()
plt.show()
```

**发现**：约61.6%遇难，38.4%生存。数据略微不均衡，但不严重。

## 2.2 缺失值分析

```python
# 方法1：pandas直接计算
missing = train.isnull().sum()
missing_pct = (missing / len(train) * 100).round(2)
missing_df = pd.DataFrame({'缺失数': missing, '缺失比例(%)': missing_pct})
missing_df = missing_df[missing_df['缺失数'] > 0].sort_values('缺失数', ascending=False)
print(missing_df)
```

## 2.5 相关性热力图

```python
# 先对分类特征编码以便计算相关系数
train_corr = train.copy()
train_corr['Sex_encoded'] = (train_corr['Sex'] == 'female').astype(int)
train_corr['Has_Cabin'] = train_corr['Cabin'].notna().astype(int)

corr_cols = ['Survived', 'Pclass', 'Sex_encoded', 'Age', 'SibSp', 'Parch', 'Fare', 'Has_Cabin']
corr_matrix = train_corr[corr_cols].corr()

# 只显示下三角
mask = np.zeros_like(corr_matrix, dtype=bool)
mask[np.triu_indices_from(mask)] = True

plt.figure(figsize=(10, 8))
sns.heatmap(corr_matrix, mask=mask, annot=True, fmt='.2f',
            cmap='RdYlGn', center=0, square=True, linewidths=0.5)
plt.title('特征相关性热力图')
plt.tight_layout()
plt.show()
```

**关键发现**（按与Survived的相关性排序）：

| 特征 | 相关系数 | 解读 |
|------|----------|------|
| Sex_encoded | **+0.54** | 最强正相关：女性 → 更可能生存 |
| Pclass | **-0.34** | 负相关：等级数越大（越低等） → 更可能遇难 |
| Has_Cabin | **+0.32** | 有客舱号 → 更可能生存（一等舱居多） |
| Fare | **+0.26** | 票价越高 → 更可能生存 |
| Age | **-0.08** | 弱负相关（但掩盖了非线性的儿童效应） |

> **注意**：Pearson相关系数只能发现线性关系。儿童生存率高的非线性模式在相关系数中被"平均掉"了。这就是为什么EDA不能只看数字，**必须画图**。

## 2.6 EDA总结：核心发现

| 发现 | 后续行动 |
|------|----------|
| 女性生存率远高于男性 | Sex是最重要特征，必须保留 |
| 一等舱 > 二等舱 > 三等舱 | Pclass强预测因子 |
| 婴幼儿生存率高 | 考虑从Name提取称谓（Master/Miss） |
| 小家庭（2-4人）生存率最高 | 构造FamilySize特征 |
| 票价严重右偏 | 需要对数变换 |
| Cabin缺失77% | 提取"有无Cabin"或"甲板"特征后丢弃原始列 |
| Age缺失20% | 按称谓/等级分组智能填充 |

# 第4章 特征工程

> **核心思想**：特征工程是"从数据中榨取信息"的艺术。业界有句名言：**"数据和特征决定了机器学习的上限，模型和算法只是无限逼近这个上限。"**

## 4.1 什么是特征工程？

特征工程 = **用人类的知识和创造力，从原始数据中构造出对模型更有用的信息**。

举个例子：原始数据有SibSp（兄弟姐妹数）和Parch（父母子女数），但模型不一定能自己学会把它们加起来。我们主动创建 `FamilySize = SibSp + Parch + 1`，就是在帮模型"理解"家庭规模这个概念。

## 4.2 Titanic特征工程清单

让我们重新开始，在合并数据上系统地做特征工程：

```python

```

# 第5章 模型构建与评估

> **核心思想**：先跑通，再优化。第一步是建立一个可工作的完整流程，而不是一开始就追求最高分。

## 5.1 基线模型

基线模型的意义：**如果没有比"猜所有人遇难"更好，那你的模型毫无意义。**

```python
# 最简单的基线：所有人都遇难
baseline_acc = 1 - y.mean()  # 遇难比例
print(f"基线准确率（所有人都猜遇难）: {baseline_acc:.4f}")
```

输出：`基线准确率: 0.6162` → 你的模型必须超过61.6%才算有用。

## 5.2 多模型对比

```python
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier, ExtraTreesClassifier
from sklearn.svm import SVC
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.naive_bayes import GaussianNB
import lightgbm as lgb

# 定义模型
models = {
    'Logistic Regression': LogisticRegression(max_iter=1000, random_state=42),
    'Decision Tree': DecisionTreeClassifier(random_state=42),
    'Random Forest': RandomForestClassifier(n_estimators=200, random_state=42),
    'Gradient Boosting': GradientBoostingClassifier(n_estimators=200, random_state=42),
    'Extra Trees': ExtraTreesClassifier(n_estimators=200, random_state=42),
    'SVM (RBF)': SVC(random_state=42),
    'KNN': KNeighborsClassifier(n_neighbors=5),
    'Naive Bayes': GaussianNB(),
    'LightGBM': lgb.LGBMClassifier(n_estimators=200, random_state=42, verbose=-1),
}

# 5折分层交叉验证
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# 评估每个模型
results = {}
for name, model in models.items():
    scores = cross_val_score(model, X, y, cv=skf, scoring='accuracy')
    results[name] = {
        'mean': scores.mean(),
        'std': scores.std(),
        'scores': scores
    }
    print(f"{name:25s} | 准确率: {scores.mean():.4f} ± {scores.std():.4f}")
```

## 5.4 为什么用交叉验证？

| 方法 | 问题 |
|------|------|
| 只看训练准确率 | 过拟合！模型可能"背答案"了 |
| 单次train/test split | 结果依赖随机种子，不稳定 |
| **K折交叉验证** | 每条数据都当过验证集，结果可靠 |

**5折交叉验证的过程**：
```
Round 1: [验证][训练][训练][训练][训练] → 分数1
Round 2: [训练][验证][训练][训练][训练] → 分数2
Round 3: [训练][训练][验证][训练][训练] → 分数3
Round 4: [训练][训练][训练][验证][训练] → 分数4
Round 5: [训练][训练][训练][训练][验证] → 分数5
最终分数 = 平均值 ± 标准差
```

> **为什么用StratifiedKFold？** 因为生存率约38%，如果随机分折，某折可能全是遇难者。StratifiedKFold保证每折中生存/遇难比例与总体一致。

## 5.5 选择最佳单模型

根据交叉验证结果，选择排名靠前的2-3个模型进行后续调优。通常 **LightGBM + 随机森林 + 逻辑回归** 是一个不错的组合。

# 第6章 超参数调优与模型融合

## 6.1 超参数调优

### 什么是超参数？

超参数是**模型训练前**设定的参数（如树的数量、深度等），区别于模型训练时学到的参数（如权重）。

| 概念 | 谁决定的 | 例子 |
|------|----------|------|
| 参数 | 模型从数据中学 | 线性回归的系数 |
| 超参数 | 你手动设定 | 随机森林的树数量、最大深度 |

### 方法1：GridSearchCV（穷举搜索）

```python
from sklearn.model_selection import GridSearchCV

# 定义参数网格
param_grid = {
    'n_estimators': [100, 200, 500],
    'max_depth': [3, 5, 7, None],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4],
}

rf = RandomForestClassifier(random_state=42)
grid_search = GridSearchCV(rf, param_grid, cv=skf, scoring='accuracy',
                           n_jobs=-1, verbose=1)
grid_search.fit(X, y)

print(f"最佳参数: {grid_search.best_params_}")
print(f"最佳CV分数: {grid_search.best_score_:.4f}")
```

### 方法2：Optuna（更智能的搜索）

```python
import optuna

def objective(trial):
    params = {
        'n_estimators': trial.suggest_int('n_estimators', 100, 1000),
        'max_depth': trial.suggest_int('max_depth', 3, 15),
        'learning_rate': trial.suggest_float('learning_rate', 0.01, 0.3, log=True),
        'num_leaves': trial.suggest_int('num_leaves', 20, 100),
        'min_child_samples': trial.suggest_int('min_child_samples', 5, 50),
        'subsample': trial.suggest_float('subsample', 0.6, 1.0),
        'colsample_bytree': trial.suggest_float('colsample_bytree', 0.6, 1.0),
        'reg_alpha': trial.suggest_float('reg_alpha', 0, 10),
        'reg_lambda': trial.suggest_float('reg_lambda', 0, 10),
    }
    
    model = lgb.LGBMClassifier(**params, random_state=42, verbose=-1)
    scores = cross_val_score(model, X, y, cv=skf, scoring='accuracy')
    return scores.mean()

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=50)

print(f"最佳分数: {study.best_value:.4f}")
print(f"最佳参数: {study.best_params}")
```

> **GridSearch vs Optuna**：GridSearch穷举所有组合，组合多时非常慢。Optuna用贝叶斯优化智能搜索，通常更快找到好参数。

## 6.2 模型融合

### 为什么融合有效？

不同模型学到的东西不一样：
- 逻辑回归学到了**线性关系**（如"女性更可能生存"）
- 随机森林学到了**非线性交互**（如"三等舱男性但有小家庭"）
- LightGBM可能学到**细微的梯度模式**

把它们的预测综合起来，往往比任何单个模型都好。

### 融合方法1：简单投票

```python
from sklearn.ensemble import VotingClassifier

# 选择表现最好的3个模型
voting_clf = VotingClassifier(
    estimators=[
        ('lr', LogisticRegression(max_iter=1000, random_state=42)),
        ('rf', RandomForestClassifier(n_estimators=200, random_state=42)),
        ('lgbm', lgb.LGBMClassifier(n_estimators=200, random_state=42, verbose=-1)),
    ],
    voting='hard'  # hard=多数投票, soft=概率平均
)

scores = cross_val_score(voting_clf, X, y, cv=skf, scoring='accuracy')
print(f"投票融合准确率: {scores.mean():.4f} ± {scores.std():.4f}")
```

### 融合方法2：软投票（概率加权平均）

```python
# soft voting需要模型能输出概率
voting_clf_soft = VotingClassifier(
    estimators=[
        ('lr', LogisticRegression(max_iter=1000, random_state=42)),
        ('rf', RandomForestClassifier(n_estimators=200, random_state=42)),
        ('lgbm', lgb.LGBMClassifier(n_estimators=200, random_state=42, verbose=-1)),
        ('gb', GradientBoostingClassifier(n_estimators=200, random_state=42)),
    ],
    voting='soft'  # 基于概率的加权平均
)

scores = cross_val_score(voting_clf_soft, X, y, cv=skf, scoring='accuracy')
print(f"软投票融合准确率: {scores.mean():.4f} ± {scores.std():.4f}")
```

### 融合方法3：Stacking（堆叠）

```python
from sklearn.ensemble import StackingClassifier

# 定义基模型
base_models = [
    ('lr', LogisticRegression(max_iter=1000, random_state=42)),
    ('rf', RandomForestClassifier(n_estimators=200, random_state=42)),
    ('lgbm', lgb.LGBMClassifier(n_estimators=200, random_state=42, verbose=-1)),
    ('gb', GradientBoostingClassifier(n_estimators=200, random_state=42)),
]

# 元模型（第二层模型，用基模型的预测作为特征）
meta_model = LogisticRegression(max_iter=1000, random_state=42)

stacking_clf = StackingClassifier(
    estimators=base_models,
    final_estimator=meta_model,
    cv=5,
    passthrough=False  # 是否把原始特征也传给元模型
)

scores = cross_val_score(stacking_clf, X, y, cv=skf, scoring='accuracy')
print(f"Stacking融合准确率: {scores.mean():.4f} ± {scores.std():.4f}")
```

## 6.3 手动加权融合（进阶）

```python
# 分别训练各模型并获取预测概率
from sklearn.model_selection import cross_val_predict

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# 获取OOF(Out-of-Fold)预测
lgbm_model = lgb.LGBMClassifier(n_estimators=200, random_state=42, verbose=-1)
rf_model = RandomForestClassifier(n_estimators=200, random_state=42)
gb_model = GradientBoostingClassifier(n_estimators=200, random_state=42)
lr_model = LogisticRegression(max_iter=1000, random_state=42)

lgbm_oof = cross_val_predict(lgbm_model, X, y, cv=skf, method='predict_proba')[:, 1]
rf_oof = cross_val_predict(rf_model, X, y, cv=skf, method='predict_proba')[:, 1]
gb_oof = cross_val_predict(gb_model, X, y, cv=skf, method='predict_proba')[:, 1]
lr_oof = cross_val_predict(lr_model, X, y, cv=skf, method='predict_proba')[:, 1]

# 尝试不同权重
best_acc = 0
best_weights = None

for w1 in np.arange(0.1, 0.6, 0.1):
    for w2 in np.arange(0.1, 0.5, 0.1):
        for w3 in np.arange(0.1, 0.5, 0.1):
            w4 = 1 - w1 - w2 - w3
            if w4 <= 0:
                continue
            blend = w1 * lgbm_oof + w2 * rf_oof + w3 * gb_oof + w4 * lr_oof
            acc = accuracy_score(y, (blend >= 0.5).astype(int))
            if acc > best_acc:
                best_acc = acc
                best_weights = (w1, w2, w3, w4)

print(f"最佳融合权重: LGBM={best_weights[0]:.1f}, RF={best_weights[1]:.1f}, "
      f"GB={best_weights[2]:.1f}, LR={best_weights[3]:.1f}")
print(f"最佳融合准确率: {best_acc:.4f}")
```

## 6.4 生成最终预测

```python
# 用最佳权重重新训练所有模型（用全部训练数据）
lgbm_model.fit(X, y)
rf_model.fit(X, y)
gb_model.fit(X, y)
lr_model.fit(X, y)

# 各模型预测
lgbm_pred = lgbm_model.predict_proba(X_test)[:, 1]
rf_pred = rf_model.predict_proba(X_test)[:, 1]
gb_pred = gb_model.predict_proba(X_test)[:, 1]
lr_pred = lr_model.predict_proba(X_test)[:, 1]

# 加权融合
w1, w2, w3, w4 = best_weights
final_pred = w1 * lgbm_pred + w2 * rf_pred + w3 * gb_pred + w4 * lr_pred
final_labels = (final_pred >= 0.5).astype(int)
```
